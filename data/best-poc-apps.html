Voxer sits between a walkie-talkie and a voice messaging app — it supports both live real-time PTT and asynchronous playback (like a voice text message). It's the better choice for casual groups where not everyone is listening at the same moment, and for mixed use cases (voice + photos + location sharing in one thread). Best for: Friend and family groups, casual outdoor use, anyone who wants PTT plus async voice messaging on their phone. Not ideal for dedicated POC radio hardware.

Which app should you use? — Quick answer

🎯
If you have an Inrico T320, AnySecu, or any Android POC radio: Use Zello (free). Map the hardware PTT button in Zello settings. Done.
🔀
If you have a TIDRADIO TD-M2 Pro: Use Odmaster — it's the native app and cheapest subscription.
🎛️
If you have a ChoYong WT2: Use the built-in POC channel system — it doesn't run third-party apps.
🚚
If you're running a business fleet: Zello Work or Hytera Horizon — depends whether you have Hytera hardware. Hytera Horizon if yes, Zello Work if mixed/other devices.
📱
If you just want PTT on your phone without buying a radio: Zello (free) for real-time PTT. Voxer if you want async voice replay too.

Frequently asked questions

What app do POC radios use? +

It depends on the radio. Android-based POC radios like the Inrico T320 can run any PTT app — Zello is the most popular. Dedicated POC radios like the TIDRADIO TD-M2 Pro use Odmaster. Enterprise radios like Hytera use Horizon. Most consumer POC radios are Zello-compatible.

Is Zello free for POC radios? +

Zello's consumer app is free for personal use with unlimited channels and contacts. Zello Work (business version with dispatch, GPS tracking, and admin console) starts at around $6–8 per user per month. Most hobbyists and preppers use the free version successfully.

What is the best PTT app for a small business? +

Zello Work is the most widely used PTT app for small businesses — proven track record across delivery, security, and construction, with a browser-based dispatch console and live GPS tracking. For businesses already using Hytera hardware, Horizon is better integrated.

Does the ChoYong WT2 use Zello? +

No — the ChoYong WT2 has its own built-in POC channel system and does not run the Zello app. For Zello compatibility, Android-based POC radios like the Inrico T320 are the better choice.
